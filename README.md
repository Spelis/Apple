# Apple

**What if you weren't the snake... but the apple?**
Apple is a playful twist on the classic Snake game where you take control of the apple, dodging the hungry snake that's determined to catch you.
(The Snake grows with photosynthesis)

## Gameplay
- Control the apple instead of the snake.
- Outmaneuver the snake as it grows longer
- Survive as long as possible, the longer you last, the longer it's tail gets.

## Controls
- By default, the game is controlled with WASD keys, which is customizable in the settings menu.

## Installation
1. Clone this repo
2. Run these commands:
```
$ make raylib
$ make
```
3. Run the game:
```
$ ./build/apple
```
